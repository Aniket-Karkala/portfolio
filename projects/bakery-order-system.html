Bakery order system

Orders in, confirmations out within five seconds.

Own buildSmall projectSoftware and networks
InputsOrder-entry form
CorePython
OutputsExcel logEmail via SMTPSMS via Twilio

The problem.

A small bakery taking orders by hand loses time and makes entry mistakes.

What is inside.

Inputs

  • Order-entry form

Core

  • Python

Outputs

  • Excel log
  • Email via SMTP
  • SMS via Twilio

How it works.

  1. An order-entry screen takes customer details, order ID and billing.
  2. Every order is logged to a spreadsheet.
  3. The customer and the owner get an email and an SMS confirmation.

What I learned building it.

  • Handles up to 100 orders a day.
