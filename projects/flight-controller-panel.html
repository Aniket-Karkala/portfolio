Flight controller panel

A physical cockpit panel for a flight simulator.

Own buildMid-size projectRobotics and play
Inputs34 toggle switchesRotary encodersPotentiometers
CoreArduino LeonardoMCP23017 port expanders
OutputsUSB HID to the simulatorOLED display

The problem.

Flying a simulator from a keyboard hides the best part: flipping real switches.

What is inside.

Inputs

  • 34 toggle switches
  • Rotary encoders
  • Potentiometers

Core

  • Arduino Leonardo
  • MCP23017 port expanders

Outputs

  • USB HID to the simulator
  • OLED display

How it works.

  1. Thirty-four toggle switches are read through I2C port expanders.
  2. Rotary encoders and potentiometers cover the continuous controls.
  3. An Arduino Leonardo presents the whole panel to the computer as a USB input device.
  4. An OLED shows panel state.

What I learned building it.

  • Built for the simulator Extreme Landings.
  • The Leonardo was chosen because it can act as a native USB device.
