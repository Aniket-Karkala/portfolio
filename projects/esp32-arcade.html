ESP32 arcade

Ten games on one small screen.

Mentored buildMid-size projectRobotics and play
InputsButtons
CoreESP32 DevKit V1Game state machines
Outputs2.4-inch ILI9341 display

The problem.

A good first big firmware project needs graphics, input, state and a menu. An arcade has all four.

What is inside.

Inputs

  • Buttons

Core

  • ESP32 DevKit V1
  • Game state machines

Outputs

  • 2.4-inch ILI9341 display

How it works.

  1. An ESP32 drives a 2.4-inch colour display over SPI.
  2. A menu launches about ten games, including Dino Run, Space Invaders, Frogger and Target Shoot.
  3. Each game is its own state machine sharing the same input and drawing code.

What I learned building it.

  • A strip of noise at the bottom of the screen came from the display library treating a 240×320 panel as 240×240. Fixing the driver configuration cleared it.
