CNC Writer Studio

A pen plotter you drive from a phone: type, draw, or teach it your handwriting.

The problem.

Hobby pen plotters normally need a PC running sender software and G-code prepared in advance. This one only needs a phone on its Wi-Fi.

What is inside.

Inputs

  • Phone dashboard
  • Handwriting capture
  • Typed or dictated text

Core

  • ESP32-S3 (dashboard, streaming)
  • Arduino Uno + GRBL (motion)

Outputs

  • Two stepper axes
  • Pen-lift servo
  • CNC Shield V3

How it works.

  1. An Arduino Uno with a CNC shield runs GRBL and owns every step pulse.
  2. An ESP32-S3 hosts the Wi-Fi dashboard and streams G-code to the Uno through a ring-buffered queue.
  3. The dashboard captures a person's handwriting and stores it as a profile in flash, so the plotter can write in that hand.
  4. Fourteen built-in image patterns can be drawn without any external software.
  5. A servo lifts and lowers the pen.

What I learned building it.

  • Motion stays on GRBL on purpose. The ESP32 never generates step pulses.
  • A single JavaScript syntax error leaves every dashboard button dead while the wiring looks guilty. The dashboard now has automated tests that run before each release.
  • The Uno transmits at 5 V, so its line reaches the 3.3 V ESP32 through a divider.
