JamoBot

Learn Korean letters by placing tiles on a robot.

Mentored buildMid-size projectRobotics and play
InputsRFID jamo tilesPN532 readers
CoreESP32u8g2 graphics
OutputsServosOLED display

The problem.

Hangul is built from letter blocks called jamo, which makes it a natural fit for physical tiles.

What is inside.

Inputs

  • RFID jamo tiles
  • PN532 readers

Core

  • ESP32
  • u8g2 graphics

Outputs

  • Servos
  • OLED display

How it works.

  1. Learners place RFID letter tiles on the readers.
  2. The ESP32 identifies the tile and responds with servo movement.
  3. An OLED shows the Hangul.

What I learned building it.

  • Built for the World Robot Olympiad.
  • Korean fonts overflowed the flash partition, and bitmap scaling had its own bugs. Most of the debugging went there.
